Schreibe Mikrotext für einen Videoblog (Website solo-stack.dev des YouTube Kanals „Solo Stack“, Deutsch ist die Hauptsprache, Englisch die zweite).

Jeder Blogartikel gibt es auf Deutsch und auf Englisch. Unter dem Titel steht eine ruhige Metazeile (Datum · Lesezeit · Format). Am Ende dieser Zeile kommt ein kurzer Link zur anderen Sprachfassung desselben Artikels. Der Linktext steht in der Zielsprache, damit ihn genau die Leser verstehen, die ihn brauchen.

Gesucht:

- "de": Linktext auf Deutsch, der auf der englischen Seite zur deutschen Fassung führt.
- "en": Linktext auf Englisch, der auf der deutschen Seite zur englischen Fassung führt.

Regeln: kurz (höchstens 4 Wörter), natürlich, persönlich und direkt, keine Bindestriche oder Gedankenstriche, keine Flaggen oder Emojis, kein Doppelpunkt.

Gib ausschließlich JSON aus: {"de": "…", "en": "…"}
