Schreibe Mikrotext für eine Website (solo-stack.dev, Homepage und Videoblog des YouTube Kanals „Solo Stack“; Deutsch ist die Hauptsprache, Englisch die zweite).

In der Navigationsleiste jeder Seite sitzt eine kleine Sprachauswahl: ein Knopf, der sichtbar nur das Kürzel der aktuellen Sprache zeigt („DE“ oder „EN“) und ein Dropdown öffnet. Darin stehen die Sprachen mit ihrem eigenen Namen (Deutsch, English); die Wahl lädt dieselbe Seite in der anderen Sprache. Für Screenreader braucht der Knopf einen zugänglichen Namen (aria-label) in der Sprache der Seite. Er steht neben dem Knopf für hell/dunkel, der „Farbschema“ beziehungsweise „Color scheme“ heißt.

Gesucht:

- "de": zugänglicher Name des Knopfs auf deutschen Seiten.
- "en": zugänglicher Name des Knopfs auf englischen Seiten.

Regeln: kurz (höchstens 3 Wörter), natürlich und direkt, keine Bindestriche oder Gedankenstriche, keine Flaggen oder Emojis, kein Doppelpunkt.

Gib ausschließlich JSON aus: {"de": "…", "en": "…"}
