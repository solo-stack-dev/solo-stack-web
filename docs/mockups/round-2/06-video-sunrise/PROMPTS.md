# Exact image-generation prompts

Generated with the built-in `image_gen.imagegen` tool. `transparent_background: false` for every call. One image per call; no HTML screenshots, packages, or production code used. The tool exposes no quality parameter; highest visual quality was requested in the prompts. Requested dimensions are prompt targets; actual dimensions are recorded in README.md.

Reference roles and exact input order are listed for each call. The supplied thumbnail is a compositing reference, not a pixel-exact paste; implementation must load the original JPEG. All new visitor text is explicitly marked TODO(copy); footer navigation and clocks were supplied by the brief/user. Episode 01 is visibly marked TODO(ep), not actual channel metadata.
