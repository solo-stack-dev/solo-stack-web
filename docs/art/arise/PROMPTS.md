Generated 2026-11-01 with the built-in `image_gen.imagegen` tool. Highest available quality was requested in every prompt; the tool exposes no separate model or quality selector. No CLI/API fallback was used. These are original production raster assets, with no visitor-facing copy. Only four PNG masters, four WebP imports, and this document were written to the repository.

## Canvas and transparency normalization

Every generated PNG was natively 1024 × 1536 RGBA. The complete canvas was retained: no crop, trim, padding change, or re-registration. All figures share the same bottom canvas baseline. The mascot's upper 45% is fully transparent; its highest hair tip is at y=0.4844.

The generator left nearly invisible alpha residue on some canvas edges. During PNG preparation, alpha ≤ 8 was set to 0, alpha ≥ 248 to 255, and intermediate alpha to round((a − 8) × 255 / 240). RGB was set to zero only for fully transparent pixels. This removes residual edge pixels while retaining intermediate opacity for smoke and painted glows; no background chroma key or segmentation was used. Master RGB artwork otherwise remains unchanged. Masters use lossless PNG compression level 9.

## WebP export

Exported with the existing Sharp 0.35.5 in a Node session whose working directory was the repository root. No dependencies were installed. Full canvas resize to height 1400 produces 933 × 1400 pixels: the nearest integer width to the 2:3 ratio. Nothing was trimmed. All four assets retain alpha.

The fine pigment and alpha grain initially exceeded the size budget. A small export-only Gaussian prefilter and separate alpha compression keep the final files below 160,000 bytes. The masters retain full resolution and unfiltered paint texture. Settings:

- `arise-knight.webp`: color quality 80, alpha quality 40, effort 6; Gaussian sigma 0.6 px.
- `arise-brute.webp`: color quality 78, alpha quality 40, effort 6; Gaussian sigma 1 px.
- `arise-assassin.webp`: color quality 78, alpha quality 40, effort 6; Gaussian sigma 0.9 px.
- `arise-mascot.webp`: color quality 80, alpha quality 80, effort 6; Gaussian sigma 0 px (no prefilter).

Export sequence: `sharp(master).resize({ height: 1400 })`, optional `.blur(sigma)`, then `.webp({ quality, alphaQuality, effort: 6 })`.
