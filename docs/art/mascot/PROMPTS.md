# Mascot production prompts

Built-in `image_gen` was used for every original illustration and pose edit. Highest available quality was requested; this interface exposes no separate quality or model selector. Every pose generation includes the selected model sheet as its first reference. Images contain no visitor-facing text. Reference paths below are the exact ordered arguments submitted. Workspace reference images were used at their generation-stage size, before the registration steps described in README.md. Generated-image paths are local provenance, not runtime dependencies.
