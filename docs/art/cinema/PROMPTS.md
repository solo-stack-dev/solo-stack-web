## Production export

The generator did not honor exact requested pixel dimensions. Final PNGs were resampled using the already-installed Sharp 0.35.5 library, with no package installation. Native dimensions are recorded in README.md; larger final dimensions do not imply added native detail. All frame/style revisions used built-in image generation.

Landscapes, cliff and beam were resized to delivery canvases. Frame regenerated twice because initial apertures were too wide. The selected frame was resized to `2000×1400` to correct its aperture proportions; negligible alpha values <=1/255 were zeroed. Production aperture `(160,224,1680,945)` was then explicitly cleared to alpha=0 to guarantee exact 16:9 geometry and remove generated residue. No new border art was drawn. This technical aperture cleanup was necessary because prompting alone did not produce a mathematically exact clean opening.

Final technical palette cleanup: for any alpha>0 pixel, exact RGB (0,0,0) was mapped to night (24,25,27), and exact RGB (255,255,255) to cream (251,243,221). All other colors and alpha values were retained.
