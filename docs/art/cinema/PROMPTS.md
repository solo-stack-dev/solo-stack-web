### Exact parameters and arithmetic

Use float64 arithmetic on sRGB code values 0–255. Here "luma" means the review's weighted sRGB formula, not linear-light luminance. Final quantization is round-to-nearest, ties-to-even (NumPy rint).

```text
W = (0.2126, 0.7152, 0.0722)
S(t) = u*u*(3-2*u), u = clamp(t, 0, 1)
Y = dot(RGB, W)
strength = S((Y-40)/35)
bright = S((Y-100)/60)
rolloff = 1-S((Y-210)/40)
bias = (1-bright)*(14,0,-11) + bright*(8,6,-16)
bias = bias - dot(bias,W)  # subtract scalar from all three channels
D = strength*rolloff*(bias + 0.022*Y)

# Direction-preserving gamut guard, no independent channel clipping.
# Epsilon only avoids division by zero; all operations are per pixel.
ratio[c] = (255-RGB[c])/max(D[c],1e-12) if D[c]>0
           else RGB[c]/max(-D[c],1e-12)
L = min(ratio[R], ratio[G], ratio[B])
k = clamp(L, 0.8, 1.2)
scale = L if L<0.8 else 1-(1.2-k)^2/0.8
RGBout = rint(RGB + scale*D)
```

The cubic transition weights have zero slope at their ends; there are no hard luma-band switches. The gamut shoulder is continuous with a continuous first derivative at L=0.8 and L=1.2. It stays below both the allowed channel headroom and unity. Highlights roll gently back to their original cream above Y=210, reaching identity at 250. Below Y=40 the entire transform is identity. No endpoint replacement was needed: the result contains no exact RGB black or white.
