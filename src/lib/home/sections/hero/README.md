## Mascot rig (`.mascot` custom properties, fractions of the image)

- `--sit-x`, `--sit-y`: the point that touches the moon rim.
- `--head` (`inset()` of the head region) and `--head-pivot`: the head is a clipped copy of the image that rotates when a shooting star passes; the body copy excludes the same region (polygon in `.mascot-body`, keep it in sync).
- `--eye-left-x`, `--eye-right-x`, `--eye-y`, `--lid-size`, `--lid-color`: CSS eyelids for the blink.
- `--glow-x`, `--glow-y`: laptop glow flicker.

A separate head layer and eyelid frames from the art agent would make this cleaner (`mascot-hero-moonrim-head.png`), but the single image works.

## Geometry

The moon circle is `--moon-r`, `--moon-cx`, `--moon-cy` on `.hero` (container units), per breakpoint. Everything that must line up with the moon reads them; change them only there. Phase math lives in `moon.ts`.
